# Python Automation

A collection of Python automation scripts for file management, system monitoring, and data protection — designed to reduce manual effort and keep systems clean, backed up, and monitored.

## 📁 Projects

| Project | Description | Link |
|---|---|---|
| **Duplicate File Cleaner & Log Automation** | Detects and removes duplicate files via MD5 checksum matching, with automated logging and email alerts. | [Repo](https://github.com/ShubhamShitoleDev/Python-Automations/tree/main/DuplicateFileCleaner) |
| **Data Shield** | Automated backup & file monitoring using checksum comparison, scheduled sync, and real-time reporting. | [Repo](https://github.com/ShubhamShitoleDev/Python-Automations/tree/main/DataShield) |
| **Platform Surveillance System** | System monitoring tool tracking CPU, RAM, disk, and network activity with scheduled logging. | [Repo](https://github.com/ShubhamShitoleDev/Python-Automations/tree/main/ProcessServillence) |
| **Empty File Cleaner & Directory Automation** | Recursively scans directories, detects and removes zero-byte files, with scheduled runs and timestamped logs. | [Repo](https://github.com/ShubhamShitoleDev/Python-Automations/tree/main/EmptyFileCleaner) |
